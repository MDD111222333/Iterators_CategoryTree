# C_Sharp_Iterators_CategoryTree

## C#_Iterators_CategoryTree

### Задание «Контрольная точка №39 — пользовательские итераторы»

Вариант 2. Дерево категорий
1. `class Category : IEnumerable<Category>` со свойствами `Name` и `List<Category> Subcategories`.
2. `GetEnumerator()` через `yield return`, рекурсивно обходящий саму категорию и ВСЕ вложенные подкатегории на любом уровне глубины (не только прямые «дети»).
3. Дополнительный метод `IEnumerable<Category> Leaves()`, возвращающий только категории без собственных подкатегорий («листья» дерева), также рекурсивно, на любом уровне глубины.
4. Постройте дерево минимум из 3 уровней вложенности и минимум 7 узлов.
5. Продемонстрируйте: обход всего дерева через `foreach` (должны быть выведены ВСЕ узлы, включая глубоко вложенные) и отдельно — только листья через `Leaves()`.
